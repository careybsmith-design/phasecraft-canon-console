# Presentation

- Shared visual styling uses semantic global tokens and existing control variants; application actions, validation and provenance stay unchanged during visual refreshes. Why: consistent presentation cannot change operating rules.
- Feed-specific reference/title presentation is opt-in on EvidenceLink; other evidence links retain their existing structure. Why: scannable feed hierarchy must not reinterpret evidence elsewhere.
- Signal intake displays a durable saved reference and explicit promotion action; mission sources remain promoted-only. Why: saving a condition must not silently authorize a mission.
